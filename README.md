Yocto metalayer for integrating the [TI Industrial Communications SDK](https://www.ti.com/tool/IND-COMMS-SDK) examples provided/adopted by [IBV](https://www.ibv-augsburg.de/) into [PHYTEC's AM64 BSP](https://phytec.github.io/doc-bsp-yocto/yocto/manual-index.html).

See the [Docu](https://docs.phytec.com/projects/yocto-phycore-am64x/en/latest/3rdpartyintegration/industrial-ethernet-comms-sdk.html) on how to use it with the Electra development board.

Note: unfortunately https://github.com/TexasInstruments/ind-comms-sdk seems unmaintained and lacks some parts that come with the installer file.
